# Area of Interest (AOI) Administrative Boundaries

This directory hosts the shapefile and vector vector boundaries for the study areas in Andhra Pradesh, India.

## Study Areas
1. **East Godavari District (Model Development Area)**
   - Center Coordinates: `17°19'16.5" N, 82°02'16.5" E`
   - Geographic Extent: ~14,266.85 $km^2$
   - Projected CRS: WGS 1984 UTM Zone 44N
   - File format: ESRI Shapefile (`.shp`, `.shx`, `.dbf`, `.prj`) or GeoJSON (`.geojson`)

2. **West Godavari District (Model Validation Area)**
   - Center Coordinates: `16°55'02.7" N, 81°20'23.79" E`
   - Geographic Extent: ~2,178 $km^2$
   - Projected CRS: WGS 1984 UTM Zone 44N
   - File format: ESRI Shapefile (`.shp`, `.shx`, `.dbf`, `.prj`) or GeoJSON (`.geojson`)

## Sources for Administrative Boundaries
- **IGISMAP Portal**: [https://igismap.com/](https://igismap.com/) (Administrative district level boundaries for India)
- **Survey of India / Bharatmaps**: [https://bharatmaps.gov.in/](https://bharatmaps.gov.in/)
- **GADM**: [https://gadm.org/](https://gadm.org/) (Level 2 administrative boundaries)
